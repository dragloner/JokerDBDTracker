# JokerDBD Tracker 1.4.12

- Новая главная с обложками стримов и отдельный каталог со списком и сеткой.
- Плавный переход из карточки в YouTube-плеер в том же окне.
- Единая панель эффектов, звука, пресетов, таймкодов, чата и комментариев.
- Интеграция Twitch удалена.
- Исправлены повторный запуск очереди, восстановление резервных копий и работа с каталогом при обрыве связи.
- Обновление поддерживает пути с кириллицей. Откат работает при недоступном журнале, а после перезапуска показывается результат установки.

Распакуйте архив Windows x64 и запустите JokerDBDTracker.exe. Пакет включает .NET. Для воспроизведения требуется Microsoft Edge WebView2 Runtime.
