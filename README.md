# JokerDBD Tracker 1.4.7

Windows-приложение с библиотекой стримов JokerDBD, встроенным YouTube/Twitch-плеером, эффектами и личным прогрессом.

## Скачать

[Последний релиз Windows x64](https://github.com/dragloner/JokerDBDTracker/releases/latest)

Скачайте `JokerDBDTracker-v1.4.7-win-x64.zip`, распакуйте в отдельную доступную для записи папку и запустите `JokerDBDTracker.exe`. .NET включён в архив; нужен [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

Обновление доступно через кнопку в приложении или замену файлов после закрытия программы. Профиль хранится отдельно от папки программы.

## Что нового

- Интерфейс Glass: боковая навигация, графитовые поверхности, фиолетовые и ледяные акценты, мягкое освещение и новые элементы управления.
- Атомарное сохранение данных и восстановление резервных копий.
- Пресеты плеера сохраняются при изменении настроек главного окна.
- Прогресс записывается во время просмотра и перед закрытием; сессии через полночь распределяются по московским календарным дням.
- Исправлены счётчики стримов, серия, перенос XP при престиже и достижения за задания.
- Награда первого просмотра выдаётся после минуты воспроизведения. Полный просмотр с 15 эффектами учитывает просмотренные участки.
- Обновления проверяются по SHA-256 и размеру; установщик создаёт резервную копию и восстанавливает файлы при сбое.
- Локальный кеш библиотеки, ручное обновление, проверка конфликтов клавиш и настройка шестого звука.
- Watch Together полностью удалён, включая TCP-сервер и управление брандмауэром.

## Возможности

- Каталог, поиск, избранное, очередь и продолжение просмотра.
- YouTube и Twitch в WebView2, полноэкранный режим, чат и комментарии YouTube.
- 15 визуальных эффектов, аудиообработка, 12 готовых пресетов и 20 пользовательских слотов.
- Шесть звуков, эквалайзер и настраиваемые горячие клавиши.
- Таймкоды с названиями, поиск и переход к сохранённому моменту.
- Уровни, престиж, ежедневные/еженедельные задания и достижения.
- Русский/английский интерфейс, масштаб, отключение анимаций, диагностика.

Twitch — отдельный режим просмотра без начисления XP и прогресса заданий.

## Клавиши

| Клавиши | Действие |
| --- | --- |
| H | Панель эффектов |
| 1–0, Q/W/E/R/T | Эффекты 1–15 |
| Y/U/I/O/P/J | Звуки |
| C / V | Чат / комментарии |
| M | Сохранить таймкод |

M и стандартные клавиши воспроизведения зарезервированы. Остальные назначения доступны в настройках.

## Данные

Профиль, настройки и таймкоды: `%APPDATA%\JokerDBDTracker`. WebView2, каталог и обновления: `%LOCALAPPDATA%\JokerDBDTracker`. Резервные копии имеют суффикс `.bak`. Неисправимые ошибки сохраняют исходные файлы для диагностики.

Профиль и настройки защищены Windows DPAPI и привязаны к учётной записи Windows. Это локальный профиль, а не серверная защита от накрутки. См. [SECURITY.md](SECURITY.md).

Для изолированной проверки можно задать переменную `JOKERDBD_DATA_ROOT`: данные и кеш будут помещены в её подкаталоги.

## Сборка

Windows и .NET 10 SDK; для регрессионных проверок JavaScript также нужен Node.js:

```powershell
dotnet build JokerDBDTracker.csproj -c Debug
dotnet run --project tests/JokerDBDTracker.RegressionTests.csproj
dotnet publish JokerDBDTracker.csproj -c Release -r win-x64 -o artifacts/release/win-x64
```

Регрессионные проверки используют отдельные каталоги. Проверяются восстановление данных, параллельные изменения таймкодов, контрольные суммы, безопасная распаковка, применение и откат обновления.

Ошибки: [GitHub Issues](https://github.com/dragloner/JokerDBDTracker/issues). Перед публикацией логов проверьте их содержимое.
