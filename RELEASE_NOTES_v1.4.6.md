# JokerDBD Tracker 1.4.6

Исправлена установка обновлений в папки с пробелами и завершающим разделителем пути. Windows PowerShell передавал такой путь в robocopy с неверной границей аргумента, поэтому копирование завершалось ошибкой 123, а программа снова запускала старую версию.

Сохранены исправление кнопок согласия YouTube из 1.4.5, дизайн Glass и остальные изменения 1.4.4. Watch Together удалён.

**Если встроенное обновление старой версии возвращает вас в старую программу:** закройте приложение, скачайте `JokerDBDTracker-v1.4.6-win-x64.zip` и распакуйте в новую папку. Запустите `JokerDBDTracker.exe` из этой папки. Профиль хранится отдельно в `%APPDATA%\JokerDBDTracker`; удалять его не нужно. Ярлык старой программы нужно заменить ярлыком новой.

Ошибка находится в установщике, уже включённом в старую версию; публикация нового архива сама по себе не изменяет этот старый установщик. После перехода на 1.4.6 исправленный установщик будет использоваться для следующих обновлений.

Проверки: сборка Release и 29 регрессионных тестов, включая реальное копирование через Windows PowerShell в папки с пробелами и завершающим разделителем, восстановление после сбоя и проверку страниц согласия YouTube.
